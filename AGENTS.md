## Agent skills

### Issue tracker

Issues are tracked locally as Markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

This repo uses the canonical triage labels unchanged: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This repo is configured as single-context: use the root `CONTEXT.md` and root `docs/adr/` when present. See `docs/agents/domain.md`.
